# paper/csl/

`ieee.csl` is the IEEE Reference Guide citation style (version 11.29.2023),
unmodified, from the Citation Style Language styles repository:
<https://raw.githubusercontent.com/citation-style-language/styles/master/ieee.csl>
(Zotero style `http://www.zotero.org/styles/ieee`, author Michael Berkowitz).

It is licensed under
[Creative Commons Attribution-ShareAlike 3.0](http://creativecommons.org/licenses/by-sa/3.0/),
as the file's own `<rights>` element says. This directory is therefore the one
part of `paper/` that is not CC BY-SA 4.0 (see the root `README.md`). Keep the
file unmodified so the notice stays accurate; `taxonomy paper` always passes it
to Pandoc with `--csl`, because Pandoc's default style is author-date.
